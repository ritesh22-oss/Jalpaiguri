# MYJPG

### Your Jalpaiguri, Connected. 💙

MYJPG is a community-focused mobile application designed specifically for **Jalpaiguri, West Bengal**. It brings essential local services, workers, shops, healthcare, blood donors, jobs, emergency assistance, government services, rentals, local businesses, and community support into one easy-to-use platform.

The goal is simple: **make it easier for people in Jalpaiguri to find the right person, service, place, or help when they need it.**

---

## 📱 About MYJPG

MYJPG acts as a digital local community hub for Jalpaiguri.

Instead of searching across multiple websites, social media groups, phone contacts, and local directories, users can discover and connect with local services from a single application.

### Core areas include:

* 👷 Daily-needed workers

# ⚙️ Installation

## 1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/MYJPG.git
```

Move into the project:

```bash
cd MYJPG
```

---

## 2. Install dependencies

```bash
npm install
```

If using Expo:

```bash
npx expo install
```

---

## 3. Configure environment variables

Create a `.env` file:

```env
EXPO_PUBLIC_FIREBASE_API_KEY=
EXPO_PUBLIC_FIREBASE_AUTH_DOMAIN=
EXPO_PUBLIC_FIREBASE_PROJECT_ID=
EXPO_PUBLIC_FIREBASE_STORAGE_BUCKET=
EXPO_PUBLIC_FIREBASE_MESSAGING_SENDER_ID=
EXPO_PUBLIC_FIREBASE_APP_ID=

EXPO_PUBLIC_GOOGLE_MAPS_API_KEY=

GEMINI_API_KEY=
MSG91_AUTH_KEY=
```

### Important

Never commit private credentials or server-side API keys to GitHub.

For example:

```text
.env
.env.local
```

should normally be included in `.gitignore`.

Public Firebase web configuration values should still have appropriate Firebase security rules and API restrictions.

---

# 🔥 Firebase Setup

Create a Firebase project and configure:

* Authentication
* Google Sign-In
* Firestore
* Storage

For web authentication, add the application's production domain to:

```text
Firebase Console
→ Authentication
→ Settings
→ Authorized Domains
```

For native Android Google Sign-In, configure:

* Android package name
* SHA-1 fingerprint
* SHA-256 fingerprint
* Google OAuth credentials
* Firebase Android configuration

Do not invent OAuth fingerprints or credentials. They must correspond to the actual build.

# 🔒 Security

MYJPG handles location, account, and community information, so security is an important part of the application.

The project should follow these principles:

* Never expose private API keys in client code
* Protect Firestore data with proper security rules
* Validate permissions server-side
* Restrict admin access
* Validate user-submitted content
* Protect emergency features from abuse
* Avoid exposing exact locations unnecessarily
* Use HTTPS
* Validate uploaded files
* Apply rate limiting where necessary
* Never trust client-side authorization alone
